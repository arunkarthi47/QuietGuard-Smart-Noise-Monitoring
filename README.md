# QuietGuard-Smart-Noise-Monitoring
IoT-based real-time noise monitoring and experimental acoustic energy harvesting

## Wokwi Simulation

The QuietGuard prototype is simulated using Wokwi.

https://wokwi.com/projects/477023167849693185

### How to Run
1. Open the Wokwi simulation using the link above.
2. Click the green Start Simulation button.
3. Observe the simulated sensor readings and system output.
